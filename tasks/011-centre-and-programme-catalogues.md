# 011 — Catalogues for the scholarship-holder survey: preparatory centres and kierunki

**Status:** Ready

## Goal

The scholarship-holder survey ([ADR 0012](../docs/adr/0012-scholarship-holder-survey.md), task [012](012-scholarship-holder-survey.md)) needs two lists that do not exist yet: the closed list of NAWA preparatory-course centres for 2026/2027, and a list of kierunek names that is as complete as possible, each mapped to an ISCED-F detailed field. This task builds both as shared, tested data; no UI, API or database change.

Intended behavior:

- **Centres** (`shared/prep-course-centres.ts`), keyed by intake year; for 2026 exactly the ten institutions of the official NAWA list *Lista Wnioskodawców otrzymujących finansowanie w programie Kursy Przygotowawcze NAWA 2026/2027* (Warsaw, 10 September 2026):

  | # | University (as in the NAWA list) | City |
  | --- | --- | --- |
  | 1 | Uniwersytet Śląski w Katowicach | Katowice |
  | 2 | Uniwersytet Łódzki | Łódź |
  | 3 | Uniwersytet Marii Curie-Skłodowskiej w Lublinie | Lublin |
  | 4 | Politechnika Krakowska im. Tadeusza Kościuszki | Kraków |
  | 5 | Uniwersytet w Siedlcach | Siedlce |
  | 6 | Uniwersytet Gdański | Gdańsk |
  | 7 | Uniwersytet Mikołaja Kopernika w Toruniu | Toruń |
  | 8 | Uniwersytet Rzeszowski | Rzeszów |
  | 9 | Katolicki Uniwersytet Lubelski Jana Pawła II | Lublin |
  | 10 | Politechnika Wrocławska | Wrocław |

  The names above were recovered from a PDF whose text layer lost some Polish letters; check every name against the original PDF.
  Each entry has: a stable `id` (ASCII slug), `university` (exact Polish name), `city`, `unit` (the name of the unit that runs the NAWA preparatory course, e.g. "Centrum Języka i Kultury Polskiej UMCS" — **found on the university's official website**), `unitSourceUrl` (the page where the unit is named), and `universityId` (the id in `shared/universities.ts`, when the university is there). When no official page names the unit, `unit` and `unitSourceUrl` are `null` and the entry is shown by the university name alone. A display helper returns `"<short university name> — <unit>"` or the university name.
- **Kierunki** (`shared/study-programmes.ts`), generated by a script from the official open data of RAD-on / POL-on (the source of studia.gov.pl):
  - included: programmes of first-cycle (*studia pierwszego stopnia*) and long-cycle (*jednolite studia magisterskie*) level, full-time (*stacjonarne*), taught in Polish, current (not closed or in liquidation), at any university in the dataset;
  - one entry per kierunek **name**, deduplicated case- and diacritics-insensitively (keep the most frequent official spelling);
  - each entry: stable `id` (slug of the normalized name), `name` (Polish, official), `isced` (ISCED-F detailed code, 4 digits) — the most frequent code among the programmes with that name; on a tie, the lowest code;
  - a header comment with the dataset URL, the download date and the filter, and a helper `iscedBroadGroup(code)` that returns the 2-digit group, whose names come from `broadGroups` in `shared/study-fields.ts`; a code whose group is missing there maps to `'other'`.
- **The script** (`scripts/build-study-programmes.mjs`) downloads the data, applies the filter and writes `shared/study-programmes.ts` deterministically (sorted by `id`, stable output for the same input). It is run by hand, never in CI or at build time.

- ADRs this task follows: [0012](../docs/adr/0012-scholarship-holder-survey.md). Replaces none.
- Sources: [NAWA list 2026/2027 (PDF)](https://nawa.gov.pl/images/Kursy-Przygotowawcze-NAWA/2026/Lista-Wnioskodawcow-otrzymujacych-finansowanie-w-programie-Kursy-Przygotowawcze-NAWA-2026-2027.pdf), from the [results page](https://nawa.gov.pl/jezyk-polski/akredytacja-nawa/akredytacja-nawa-nabory-do-programow/kursy-przygotowawcze-nawa/wyniki-naboru-2025) supplied by the maintainer; RAD-on open data at `radon.nauka.gov.pl` (find the official programme dataset and its fields).
- Dependencies and decisions already made:
  - Closed centre list, no "other"; the unit is found on each university's site and checked by the maintainer; a missing unit means university only (maintainer, 2026-11-22).
  - Kierunek list built from RAD-on / POL-on with ISCED-F codes; aggregates use the 11 broad ISCED-F groups (maintainer, 2026-11-22).
  - Fetching public open data while running the script is allowed; nothing is deployed.

## Scope

- In scope: the two data modules, the script, unit tests, a short "Catalogues" note in `docs/architecture.md` (where the lists come from and how to refresh them).
- Out of scope: UI, API, database, translations of kierunek names (Polish only, like cities), editing `shared/study-fields.ts`, `shared/universities.ts` entries (if a centre's university is missing there, leave `universityId` null and report it).
- Files or directories assigned to this task: `shared/prep-course-centres.ts` (+ test), `shared/study-programmes.ts` (generated, + test), `scripts/build-study-programmes.mjs`, `docs/architecture.md`.
